# Оформление торрентов Lampa

Самостоятельный плагин `torrent-style.js`, версия 1.0.1. Без привязки к ByLampa, внешних библиотек и сетевых запросов. Исходные названия, ссылки и значения раздач не изменяются.

## Установка через GitHub Pages

1. Загрузите `torrent-style.js` в папку вашего репозитория, опубликованную через GitHub Pages. При публикации из корня ветки положите файл в корень.
2. Дождитесь успешной публикации Pages. Откройте адрес файла в браузере: должен отображаться JavaScript, а не страница GitHub или ошибка 404.
3. Отключите другие плагины оформления торрентов.
4. В lampa.mx откройте настройки расширений, добавьте адрес файла и перезапустите приложение.

Пример адреса для репозитория `lampa-torrent-style`:

```text
https://ВАШ-ЛОГИН.github.io/lampa-torrent-style/torrent-style.js
```

Если репозиторий называется `ВАШ-ЛОГИН.github.io`, адрес будет `https://ВАШ-ЛОГИН.github.io/torrent-style.js`. Для собственного домена используйте домен из настроек Pages.

## Оформление

| Показатель | Цвета |
| --- | --- |
| Сиды | Меньше 5 — красный; 5–19 — янтарный; от 20 — зелёный |
| Скачивающие | Голубой |
| Битрейт | Меньше 20 — голубой; от 20 до 50 — янтарный; от 50 Мбит/с — красный |
| Размер | Меньше 5 — зелёный; от 5 до 10 — голубой; от 10 до 25 — янтарный; от 25 ГБ — красный |
| Разрешение | SD — красный; HD — янтарный; FHD — зелёный; 2K — голубой; 4K/8K — фиолетовый |

Разрешение оформляется в существующей плашке `.m-resolution`. Если её нет, но в названии раздачи явно указано разрешение, плагин добавляет плашку в строку деталей. HDR сам по себе не считается разрешением 4K. Неизвестные значения остаются без окраски.

Пороги доступны в объекте `config` в начале JS-файла. Настройки не добавляются в меню Lampa. Цвет не является оценкой качества видео или гарантией скорости просмотра.

## Обновление и удаление

Для обновления замените JS-файл в репозитории и дождитесь публикации. Если клиент использует старую копию, замените адрес расширения на тот же адрес с новым параметром, например `torrent-style.js?v=2`, и перезапустите клиент. Не добавляйте вторую активную копию расширения.

Для удаления отключите или удалите расширение и перезапустите Lampa. Для диагностики из консоли доступны `LampaTorrentStyle.version`, `LampaTorrentStyle.refresh()` и `LampaTorrentStyle.destroy()`.

## Проверка на устройстве

Проверьте открытие списка торрентов, сортировку, фильтры, подгрузку результатов и повторный вход в список. Убедитесь, что длинные названия и раздачи без битрейта отображаются корректно, а управление пультом сохранилось.

Плагин рассчитан на разметку `.torrent-item` и её поля `__seeds`, `__grabs`, `__bitrate`, `__size`, `__title`, `__details`, `__ffprobe`. Работа на текущей версии lampa.mx и конкретном телевизоре требует проверки после установки. Для устаревших браузеров без MutationObserver автоматическое оформление новых результатов не поддерживается.

# Torrent Audio для Lampa — 0.1.0

Экспериментальный плагин для встроенного плеера Lampa, в том числе при запуске через MediaStationX. Дорожки читает из TorrServer/GStreamer `/gst/{hash}/probe?index={fileIndex}`. Выбор в штатном меню «Аудиодорожки» меняет параметр `audio` у HLS-потока.

## Установка

1. Опубликуйте `torrent-audio.js` на своём GitHub Pages рядом с другими плагинами.
2. В расширениях Lampa добавьте URL опубликованного файла, например `https://lod255.github.io/lampa_plugins/torrent-audio.js?v=0.1.0`.
3. Перезапустите Lampa и заново откройте торрент. В панели встроенного плеера выберите аудиодорожку.

Сервер по умолчанию: `http://192.168.1.2:8090`. При другом адресе выполните в консоли Lampa после загрузки плагина:

```javascript
LampaTorrentAudio.setGateway('http://АДРЕС:ПОРТ');
```

Затем заново откройте торрент. Адрес сохраняется в настройках Lampa. Отдельного пункта настройки адреса в интерфейсе пока нет.

Прямые ссылки `/stream/…?link={40-символьный-хэш}&index=N` преобразуются в HLS только при совпадении имени сервера с настроенным адресом. Готовые ссылки `/gst/{hash}/master.m3u8` работают на своём исходном сервере. Плагин не добавляет торренты на другой сервер, поэтому шлюз должен обслуживать тот же TorrServer. Индекс файла сохраняется без изменения, индекс аудио берётся из `Tracks[].Index`, а не из позиции элемента.

## Переключение

Меняется поток внутри открытого плеера через API PlayerVideo. Повторного Player.play() нет: экран фильма, плейлист и рекламный запуск не перезапускаются. Во время подготовки HLS возможна пауза. Плагин пытается вернуть текущую позицию и состояние паузы в течение 60 секунд; сервер должен выдавать HLS с поддержкой перемотки. Если восстановить позицию не удалось, появится сообщение. Это поведение ещё необходимо проверить на телевизоре.

## Требования и ограничения

- Рабочий GStreamer-шлюз с HLS и JSON `/probe` формата `{"Tracks":[{"Type":"audio","Index":1,"Title":"HDrezka Studio","Language":"ru","Channels":2}]}`.
- Сервер доступен с телевизора и разрешает запросы CORS со страницы Lampa. Чтение `/probe` через curl само по себе не проверяет CORS браузера. При HTTPS-странице HTTP-сервер также может блокироваться браузером.
- Встроенный плеер; внешние приложения плагином не управляются.
- Lampa должна предоставлять Player.listener, PlayerPanel.setTracks и PlayerVideo. Проверено по текущим открытым исходникам, не по установленной версии MediaStationX.
- Реальное переключение, пульт, возврат позиции, пауза, переход между сериями и удаление плагина требуют проверки на Samsung. Локальные проверки используют модель API, а не реальный декодер.
- При ошибке подготовки нового HLS сервером плагин показывает сообщение; автоматического восстановления старого потока после асинхронной ошибки пока нет.

Для удаления отключите расширение и перезапустите Lampa. `LampaTorrentAudio.destroy()` снимает обработчики и обёртку меню, но не возвращает уже открытый HLS-поток к прямому воспроизведению. `LampaTorrentAudio.refresh()` повторяет запрос дорожек текущего фильма.

Исходники API: https://github.com/yumata/lampa-source/tree/main/src/interaction/player
